# Sorting fruits

WebGL 2d игра про сортировку фруктов по цветам. Простая графика и приятный геймплей, с множеством уровней! Есть несколько бонусов для помощи в прохождении уровня.
Выложена на Яндекс игры.

[**🎮 Сыграть в WebGL билд**](https://yandex.ru/games/app/480306?lang=ru)

## 🛠️ Стек технологий
- Unity 2022.3.61f1
- Библиотека анимаций LitMotion (аналог DOTween)
- DI Container Reflex
- Newtonsoft Json
- Addrassables
- Так-же активно пользовался GitHub Copilot'ом в Visual Studio

## ⚙️ Как запустить проект
Проект создан на версии Unity 2022.3.61f1. [Скачать версию с официального сайта](https://unity.com/ru/releases/editor/whats-new/2022.3.61f1#installs).

### Установка
1.  Склонируйте репозиторий.
2.  Откройте проект [на версии Unity 2022.3.61f1](https://unity.com/ru/releases/editor/whats-new/2022.3.61f1#installs).
4.  Откройте сцену `MainScene` из папки `Assets/_Project/Scenes/`.
5.  Запустите сцену
